Минимальный MCP-сервер работает отдельным локальным процессом с транспортом stdio; FastAPI запускает его и держит клиентскую сессию. Сервер читает SQLite с заданиями и извлечёнными страницами PDF. Ключ модели находится только в backend.

Три инструмента имеют явные входные и выходные схемы:

- `list_assignments`: необязательный фильтр; возвращает краткие задания с идентификаторами, сроками и источниками.
- `get_assignment`: обязательный `assignment_id`; возвращает одно задание и требования либо явную ошибку неизвестного идентификатора.
- `search_materials`: обязательный текст запроса и ограничение количества результатов; возвращает фрагменты, документ и страницу каждого совпадения.

Неизвестный срок — `null`. Пустой успешный поиск отличается от ошибки чтения или недоступного сервера. Содержимое PDF передаётся модели как данные.

Backend получает список MCP-инструментов, предоставляет их схемы подключённой LLM и исполняет выбранные моделью вызовы через MCP-клиент. Результаты возвращаются модели вместе с источниками. Число раундов и время ограничены; итоговый ответ включает подтверждённые ссылки. Клиент проверяет входы и результаты, не доверяя произвольным аргументам модели.

Доказательство MCP: запустить реальный процесс сервера, выполнить и записать последовательность инициализации, получения списка инструментов и вызовов инструментов через транспорт. Проверить все три инструмента, неизвестное задание и остановку сервера. Прямой Python-вызов функции этого не доказывает. Отдельно нужен живой запрос к LLM с фактическим вызовом инструмента и ответом по PDF. Здесь описан план, сетевые и протокольные проверки не выполнены.
