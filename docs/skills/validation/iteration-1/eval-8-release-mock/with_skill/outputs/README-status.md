# Подтверждённая область проверок

Статус: готовность к защите не подтверждена. Основание ниже — сведения из сообщения пользователя, не новый независимый прогон.

- Offline-тесты проходят с mock HTTP и LLM. Это свидетельство только для проверенных смоделированных путей.
- Инструменты проверены прямым вызовом функций. Протокольные discovery/call и транспорт MCP ещё не подтверждены.
- Публичный /health отвечает. Пользовательский live-чат по этому URL не проверен; сам URL в данный отчёт не предоставлен.
- SQLite пересоздаётся при рестарте. Назначение базы и воспроизводимость seed/сохранность пользовательских изменений требуют отдельной проверки.
- Нет представленных результатов live LLM Eval, hosted-сценария и полной репетиции защиты. Значения метрик не заявлены.

Для заявления о MCP нужны фактические SDK-client discovery/call и smoke транспорта с ошибочными путями. Для готовности сервиса — live-сценарий с источниками по публичному URL до/после рестарта, воспроизводимый запуск, проведённый Eval и материалы сдачи.

Неизменяемая demo-база может восстанавливаться из версионированного seed. Если в SQLite записываются пользовательские изменения, их потеря при рестарте требует исправления постоянного хранения. Тип данных пока не установлен.

Места фиксации фактических доказательств после выполнения: commit и lock; дата/зона; SDK/транспорт; provider/model/settings; команды и exit codes; trace; полный манифест и результаты Eval с ошибками; публичные URLs; результат рестарта; измеренное время защиты. До выполнения эти поля не заменяются фиктивными успешными значениями.
