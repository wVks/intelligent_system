# Проверки, ещё не выполненные в этом отчёте

| Уровень | Проверка | Свидетельство |
|---|---|---|
| Offline | Сохранить существующие команды и реальные результаты mock-тестов | Log, commit, scope mocks; не live-метрика |
| MCP protocol | initialize, discovery трёх инструментов, calls через настоящий клиент | SDK version, source IDs, request/call IDs, status |
| MCP transport | Старт/подключение/поиск/закрытие в выбранном stdio или HTTP | Команда, exit code, безопасный trace; ошибка/timeout отдельно |
| Backend integration | Fake-модель вызывает настоящий MCP; запрещённое имя/аргументы; бюджет loop | Не более заданного max calls/deadline, корректные статусы |
| Live | Реальная LLM получает tool results, ответ соответствует PDF | Ответ и source/excerpt; неизвестная дата null |
| Hosted | Основной и неизвестный вопрос через публичный UI | Фактический URL, дата, ответы и trace |
| Restart | Повторный пользовательский сценарий и сравнение состояния SQLite | Seed hash/ID либо сохранная пользовательская тестовая запись |
| Reproducibility | Чистый запуск по README/lock | Реальные команды и exit codes |
| Eval | Факт/неверная опора/неизвестное/injection/transport/план | Полный manifest, результаты, evidence; timeout и missing не исключены |
| Submission | README 9 разделов, публичный репозиторий и сервис, HTML | Две действительные ссылки для LMS; интерактивность и измеренный прогон ≤10 минут |

Порядок: сначала запуски и MCP, затем LLM, хостинг и рестарт, Eval и материалы. Доступа к ключу/хостингу нет — фиксировать «не проверено» с причиной. Прямой Python-вызов оставить unit-тестом, не выдавать за MCP. Отчёт не назначает баллы. Пользовательские данные при проверках не удалять: использовать отдельную тестовую базу/среду.

Для неизвестной SQLite-модели сначала осмотреть схемы/пути записи и seed. Immutable seed — проверить одинаковые исходные ID/требования после рестарта и документировать ограничение. Изменяемые данные — выбрать доступное постоянное хранение, затем проверить сохранность; поставщик заранее не навязывается.

Команды приложения/URL не указаны, поскольку в исходном снимке они отсутствуют. Подставить реальные из существующего проекта перед выполнением, не выдумывать успешные логи.
