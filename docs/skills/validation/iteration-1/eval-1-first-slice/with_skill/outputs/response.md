Первый срез: студент спрашивает «Что отправить в LMS?» и получает: «Две ссылки: публичный репозиторий с README.md и интерактивной HTML-презентацией; работающий сервис». Каждое требование подтверждается страницей 1 исходного PDF. Даты сдачи нет: `due_date: null`, `due_at: null`.

Минимальные данные: одно задание `personal-project`, курс `course-1`; `title`, массив требований, критерии, неизвестные сроки и `source_refs`. Фрагмент `pdf-p1-lms`: `source_id: project-pdf`, `page: 1`, `section: null`, `excerpt: «В LMS загрузить ссылку на публичный репозиторий с HTML-презентацией и README и ссылку на работающий сервис»`, `href: /materials/project-pdf#page=1`. Это проектные идентификаторы, не существующие маршруты. Остальной PDF сохранить как исходник; не создавать фиктивные задания.

Маршрут: HTML → `POST /api/chat` → backend с ключом LLM → разрешённый tool call модели → настоящий MCP-клиент → MCP-сервер → SQLite → фактический tool result с ID вызова → модель → проверка опоры утверждений → UI. Для этого вопроса достаточно `search_materials({query:"Что отправить в LMS?",limit:3})`; каталог трёх инструментов обнаруживается по MCP. Локально сервер — управляемый stdio-подпроцесс; stdout оставляем протоколу. Модель объясняет найденное, код проверяет схемы/ссылки и бюджет вызовов.

Минимум будущих файлов: `pyproject.toml` и lock; `app/main.py` (FastAPI, lifespan, выдача PDF); `app/chat.py` (LLM и ограниченный tool loop); `app/mcp_client.py`; `app/mcp_server.py` (три читающих инструмента); `app/store.py`; `data/seed.json` и исходный PDF; `app/static/index.html`; `tests/test_lms_flow.py`. SQLite создаётся из seed; API-ключ только в серверном окружении. Реальная LMS, аккаунты, уведомления и vector DB не нужны.

Критерий приёмки: в браузере вопрос проходит через подключённую LLM и реальный MCP, возвращает обе ссылки как виды требуемых результатов и подтверждение страницей 1; ссылка открывает PDF. Trace без секретов содержит discovery, tool call и источник. Отдельно: отключённый MCP даёт «источник недоступен», а не «заданий нет»; неизвестная дата не появляется. UI показывает ожидание/ошибку/пустой ответ, безопасно отображает текст, работает с клавиатуры. Offline-успех не заменяет этот live-критерий.
