Симптомы указывают на две возможные независимые причины: неограниченный цикл вызовов модели и подмена ошибки MCP пустым списком. Без кода это гипотезы; сначала воспроизводим обе по отдельности.

1. Зафиксировать один вопрос, версию модели, лимиты и данные. Подставить модель, которая каждый раз просит `search_materials`. Записать число вызовов и время; затем отдельно отключить MCP и зафиксировать текущий ответ. Не записывать ключи или полный конфиденциальный контекст.
2. Если бесконечный цикл подтверждён, добавить предел, например 5 вызовов на запрос, общий deadline 30 секунд и отдельный timeout каждого вызова в пределах оставшегося времени. Повтор одинакового поиска без новых данных останавливает цикл раньше. При исчерпании бюджета вернуть понятный статус неполного ответа. Не повторять один и тот же timeout автоматически без ограничения.
3. Если ошибка превращается в `[]`, исправить именно эту ветку: успешный пустой результат означает «поиск выполнен, совпадений нет»; ошибка подключения/timeout означает «данные сейчас недоступны». Ошибку нельзя передавать модели как отсутствие заданий. Проверить отмену дочернего вызова и освобождение сессии.
4. Сохранить прямой unit-тест функции поиска, но добавить интеграционный тест отдельного MCP-сервера с initialize, tools/list и tools/call. Только он проверяет контракт и транспорт.

Приёмка: повторяющийся поиск заканчивается в заданном бюджете и не превышает лимит; отключение MCP не даёт уверенного «заданий нет»; действительно пустая база возвращает отдельное сообщение об отсутствии найденных записей; нормальный вопрос о LMS возвращает требования со страницей 1. Дополнительно проверить неверные аргументы и прерывание MCP посередине вызова.

Каждую причину исправлять отдельным небольшим изменением и повторять соответствующее воспроизведение. Затем выполнить оба сценария вместе и один обычный запрос. Fake-модель подходит для проверки ограничителей, но не подтверждает поведение подключённой модели. Фактических прогонов сейчас нет: в испытании нет приложения, сети и доступа к сервисам. Новые функции MVP не требуются.
