Минимальная схема: браузер → FastAPI → адаптер LLM и MCP-клиент → отдельный MCP-сервер → SQLite. Браузер не обращается к модели или SQLite напрямую. Для локального MVP достаточно MCP поверх stdio с отдельным процессом сервера; HTTP для MCP пока не нужен. Самодельный REST endpoint или прямой вызов Python-функции не доказывает работу MCP.

Инструменты:

- `list_assignments`: необязательный фильтр; возвращает список `{id, title, due_at, source_refs}`. `due_at` может быть `null`.
- `get_assignment`: обязательный `assignment_id`; возвращает требования, срок и ссылки на фрагменты. Неизвестный id даёт явную ошибку отсутствия записи.
- `search_materials`: обязательная непустая строка `query`, ограниченный `limit`; возвращает `{source_id, page, excerpt}`. Поиск по тексту PDF, без векторной БД в первом срезе.

SQLite хранит задания, документы и фрагменты со страницами. Первичные записи проверяются по PDF: сдача двух ссылок — страница 1; дата сдачи — `null`. Встроенные инструкции из материалов остаются данными.

Backend открывает MCP-сессию, выполняет инициализацию, получает `tools/list`, переводит описания и схемы в формат инструментов провайдера LLM. Модель получает вопрос; запрос инструмента проверяется по схеме и выполняется через MCP `tools/call`. Результат связывается с идентификатором вызова и возвращается модели. Ответ с источниками отправляется браузеру. У цикла есть общий срок и предел вызовов; ключ модели только на сервере. Ошибка транспорта, ошибка инструмента и пустой результат различаются.

Доказательство по уровням:

1. Unit: проверка поиска и схем, без утверждения о транспорте.
2. Интеграция: запустить отдельный MCP-процесс, выполнить initialize → tools/list → tools/call для всех трёх инструментов. Сохранить обезличенный trace: сессия, имя, аргументы, статус и длительность.
3. Отрицательная проверка: завершить MCP-процесс и убедиться, что клиент сообщает ошибку, а не пустой список.
4. С подключённой моделью задать вопрос о LMS и проверить всю цепочку до ответа со страницей 1. Этот этап требует ключа и сети и сейчас не выполнялся.

Приложения ещё нет; это конкретный план реализации и доказательств, не отчёт о работающем MCP.
