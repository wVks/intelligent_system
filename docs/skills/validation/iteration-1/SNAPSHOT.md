# Снимок инструкций

skill-snapshot содержит точные версии skills этой итерации. Для повторения
скопируйте его содержимое в .agents/skills отдельного временного проекта
и добавьте исходные AGENTS.md, docs/project-brief.md и inputs этой проверки.
Относительные ссылки внутри снимка рассчитаны на исходное расположение
.agents/skills, а не на каталог архива. Не подменяйте текущие рабочие skills.

Каждая конфигурация исполнялась независимым агентом с унаследованной моделью.
Без-skill агенту давались только context.txt/prompts; он инструктирован
не читать проектные skills и чужие outputs. Вызовы приложения не выполнялись.
