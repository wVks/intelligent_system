Требования курса — с источником

Студент спрашивает: «Что отправить в LMS?»

Ответ: ссылка на публичный репозиторий с README и HTML-презентацией + ссылка на работающий сервис.

Источник: исходный PDF, стр. 1. Дата сдачи не задана.

0:00–1:00

Один курс, один проверяемый сценарий

  • Веб-чат и список заданий, PDF как первый источник.
  • Python/FastAPI, SQLite, подключённая LLM, собственные MCP-клиент и сервер.
  • Критерий: ответ подтверждён источником, неизвестный срок остаётся null.

Локальный запуск сообщён пользователем. Полная цепочка и согласование темы пока не подтверждены.

1:00–2:00

Как проходит запрос

Браузер → FastAPI → LLM → tool call
                       ↓
                  MCP-клиент ⇄ MCP-сервер → SQLite/PDF
                       ↓
                 Ответ + источник
Раскрыть проект примера MCP-вызова
search_materials({query: "Что отправить в LMS?", limit: 3})
→ matches: [{source_id: "project-pdf", page: 1, excerpt: "В LMS загрузить..."}]

Это проектный пример, не запись выполненного обмена. Нужны discovery/call настоящим клиентом и smoke транспорта.

  1. Основной вопрос → обе ссылки по смыслу, источник стр. 1.

  3. MCP отключён → понятная ошибка источника.

Нет ключа LLM и доступа к хостингу. Публичная ссылка отсутствует; офлайн показ не заменяет живой чат.

Eval не запускался. Процент качества отсутствует.

  • Проверить факт и соответствие ссылки утверждению.

Конфигурацию, число случаев, реальные результаты, одну ошибку с причиной и проверенное исправление. Offline, MCP, live и hosted — отдельные уровни.
