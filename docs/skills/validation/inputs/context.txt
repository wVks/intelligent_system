Первая версия: простой веб-чат и список заданий, Python/FastAPI, SQLite, подключённая LLM по API, собственный MCP-сервер с инструментами list_assignments, get_assignment, search_materials. Реальной LMS, аккаунтов и уведомлений в MVP нет. Исходный PDF — первый реальный материал. Приложения пока нет. Неизвестные данные нельзя выдавать за факты.
