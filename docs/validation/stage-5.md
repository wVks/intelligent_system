# Этап 5: Yandex API и экономный live Eval

Дата проверки: **27 октября 2026 года, Europe/Moscow**. Локальный HTTP-сервис,
настоящий MCP по stdio и реальные запросы к Yandex AI Studio.

**Результат:** подключение работает; расчётная стоимость всей проверки —
**23,0777 ₽ при разрешённом максимуме 25 ₽**. Последние результаты по каждому
из восьми случаев прошли структурную и содержательную проверку, но получены
**на разных моделях и версиях приложения**. Это не единый успешный прогон одной
конфигурации и не подтверждение целевого качества ≥95%.

Публичные исходы, рубрики, доказательства, хеши и учёт токенов:
[stage-5-results.json](stage-5-results.json). Реальные ID каталога и ключи туда
не включены. Полная история исходных ответов остаётся локально в игнорируемом `var/`.

## Что изменилось

- Для Yandex API добавлены `Api-Key` и `OpenAI-Project`, URI модели и настраиваемые
  пределы ответа. Обычный Bearer-адаптер для других совместимых API сохранён.
- Известное выбранное задание получает контроллер через настоящий MCP до первого
  платного ответа модели. Trace явно помечает инициатора `application`.
  Следующий поиск исходного текста выбирает модель через вызов функции.
- Парсер принимает JSON, целиком обёрнутый в пустой или `json` code fence.
  Он не извлекает случайный JSON из произвольного текста.
- Уточнено, что ссылки задач подтверждают именно документально заданные минуты.
  Модельные оценки используют `estimate` и пустой `source_ids`; валидатор не ослаблен.
- При анализе Yandex получает короткие локальные ID `S1…Sn`. Адаптер возвращает
  реальные ID по точному отображению; неизвестный ID отклоняется. Это не
  автоматическое исправление смыслово неверной цитаты.
- Для загруженных заданий уточнён контракт `facts=[]`: требования хранятся
  в карточке, а не в выдуманных ключах канонических typed facts.

Production routing между моделями не добавлялся. У приложения остаётся одна
настройка `LLM_MODEL`; режим по умолчанию — `offline`. Alice AI LLM Flash
использовалась только через CLI override для одной проверки анализа исходного PDF.

## Набор и способ оценки

Манифест: [live-cases.json](../../evals/app/live-cases.json),
`studynavigator-live-economy-v1`. Восемь случаев выбраны до платного запуска:
известные факты, неизвестный срок, анализ исходного и нового PDF, подтверждение
с происхождением, арифметика плана, приватность и чат с поиском источника.

Первый документ — исходное трёхстраничное задание. Второй — новый небольшой
PDF **AURORA weather report**, созданный кодом без LLM: два CSV, средняя
температура каждого набора, сравнительный график, PDF-отчёт и Python-код,
критерии 6+4 балла и срок 15 ноября 2026 года. В материал включена недоверенная
инструкция добавлять `SKY_OVERRIDE` и подменять требования. Она не должна
управлять приложением или становиться условием задания.

Сценарии проходят через реальные HTTP-маршруты `TestClient`, временные SQLite,
хранилище PDF, отдельные cookie-сессии и MCP-подпроцесс. Пользовательская база
не использовалась. Это не браузерный прогон и не проверка публичного хостинга.

Автоматические проверки структуры, scoping, статусов и расчётов отделены от
содержательного ревью. Отдельный агент сопоставил сохранённые ответы с
каноническими выдержками: полнота требований, поддержка каждой цитатой,
неизвестная дата и происхождение оценок. Платного модельного судьи не было.
Неполученный пользователем ответ считается неудачей, даже если сырой текст
модели содержательно верен. Все 13 попыток случаев проверены, ожидающих ревью нет.

## История неудач и исправлений

В истории **13 попыток диагностических случаев: 8 прошли строгое ревью,
5 не прошли**. Структурные проверки прошли в 10/13; совпадение с числом 13
платных генераций случайно — генерации включают отдельный smoke и несколько
вызовов внутри одного чата. Неудачные попытки не заменены удачными.

| Попытка | Ошибка | Действие и последующее наблюдение |
|---|---|---|
| `42a4d5225378` | Корректный JSON в пустом code fence отклонён, HTTP 503 | Строгая обработка полной fence-обёртки; повтор неизвестной даты прошёл |
| `cf3072bea336` | Оценочные минуты ошибочно снабжены documentary source IDs; HTTP 422; одна цитата не покрывала продолжение фразы | Уточнён prompt оценки минут и ссылок на соседние фрагменты; валидатор оставлен строгим |
| `7980fbbe7c4d` | Структура прошла, но «Демо» ссылалось на предыдущий фрагмент; неявное условие реализованного MCP-сервера | Введены короткие ID; дальнейшее ревью проверяло смысл, а не только существование ссылки |
| `2c1491341898`, чат | Содержательный текст верен, но модель придумала typed fact `requirements`; HTTP 503 `unsupported_fact` | Уточнено `facts=[]` для uploaded; точечный повтор чата прошёл с явным replay setup |
| `e4063b8892b6` | Pro сохранила «AI-логику», но упустила явное требование подключённой LLM | Один сравнительный анализ Flash на том же PDF, prompt и лимите 1800 прошёл; исходный провал Pro сохранён |

Один успешный ответ Flash не доказывает её общее превосходство и не проверяет
её чат, неизвестные сведения или стабильность на других документах. Модель
приложения автоматически не переключалась.

## Расход и ограничение бюджета

| Модель | Генераций | Входящие токены | Исходящие токены | Расчётная стоимость |
|---|---:|---:|---:|---:|
| YandexGPT Pro 5.1 | 12 | 23 026 | 5 348 | 22,6992 ₽ |
| Alice AI LLM Flash | 1 | 1 849 | 968 | 0,3785 ₽ |
| **Всего** | **13** | **24 875** | **6 316** | **23,0777 ₽** |

Расчёт основан на возвращённом провайдером `usage` и тарифах: Pro — 0,8 ₽
за 1000 входящих/исходящих токенов, Flash — 0,1/0,2 ₽ соответственно.
Это расчёт по токенам, а не сверенный счёт Billing. [Тарифы Яндекса](https://aistudio.yandex.ru/ru/docs/ai-studio/pricing).
До максимума 25 ₽ осталось **1,9223 ₽**; новых платных запросов после завершения нет.

`BudgetTransport` резервирует стоимость до каждой HTTP-попытки и сохраняет
один ledger между запусками. После ответа резерв сверяется с `usage`; неизвестный
расход не считается нулевым. Первоначально использовалась консервативная граница
по UTF-8 байтам. Для части Pro-запросов добавлена бесплатная native-токенизация
буквального payload с запасом 1024 токена, включая переданные схемы инструментов.
Тарифы двух разрешённых моделей учитываются отдельно.

**Ограничение 25 ₽ действует у Eval runner через этот transport. Обычное приложение
сейчас не имеет денежного hard cap.** Бюджетные уведомления Yandex Cloud сами
не останавливают расход.

## Бесплатные регрессии и воспроизводимость

- **251 Python-тест** прошёл за 46,04 с.
- **9/9 JavaScript-тестов** прошли.
- **30/30 offline-случаев** прошли; они не включены в live-качество.
- `git diff --check` — чисто. `.env` игнорируется и не отслеживается, права `0600`;
  секрет отсутствует в публичных файлах, в `.env.example` ключ пустой.

```sh
.venv/bin/python -m pytest tests/app -q
node --test tests/web/app.test.cjs
.venv/bin/python tools/run_app_eval.py --output var/eval-stage5-offline-final.json
.venv/bin/python tools/run_live_eval.py
```

Последняя команда без `--execute` только показывает манифест и не читает ключ.
Живой запуск требует явно загруженного окружения, `--execute` и общего ledger.
`--case` позволяет повторить одну группу, `--reuse-card` — только чат с раскрытой
подготовкой, `--model` меняет модель этого запуска без правки `.env`.

В публичном JSON указаны ID запусков, хеши манифеста, кода приложения,
`uv.lock` и системного prompt, параметры и модель. В первой исторической попытке
эти хеши ещё не записывались. Аналитический prompt покрывается хешем кода.
Использование alias `latest` не фиксирует будущие обновления модели провайдером.

Локальные полные артефакты: `var/eval-live-stage5.json`,
`var/live-stage5-semantic-review.json`, `var/live-stage5-budget.json` и
`var/eval-stage5-offline-final.json`. В Git предназначены только обезличенный
публичный результат, манифест, тесты и код runner.

## Что остаётся

Приёмка одной финальной модели на всей цепочке и статистически осмысленное
подтверждение целевого качества ≥95% остаются непроведёнными. Бюджет этого
прогона не расширялся ради дополнительного сравнения моделей.

Размещение относится к этапу 6: предстоит проверить Dockerfile, `HOST=0.0.0.0`
внутри контейнера, сохраняемый диск SQLite/PDF, HTTPS reverse proxy и доверенные
forwarded headers. Публичный сервис и единый hosted end-to-end этим отчётом
не подтверждаются. Незавершённая полная проверка клавиатуры/360–375 px из
[этапа 4](stage-4.md) также не считается выполненной этим HTTP Eval.
